# ПР12. Ответы на контрольные вопросы

## 1. Для чего нужен enum и какую проблему решает использование именованных значений вместо чисел или строк?

- enum нужен для хранения ограниченного набора вариантов. Он решает проблему опечаток в строках и делая код понятным.

## 2. Какие целочисленные значения по умолчанию получают элементы enum?

- Начиная с 0 по порядку

## 3. Что позволяет сделать switch с переменной типа enum?

- Перебрать все заранее известные варианты enum и выполнить для каждого свой блок кода или вернуть нужный результат.

## 4. Что означает int? и какое дополнительное состояние появляется у такой переменной по сравнению с обычным `int?

- Это nullable-тип. У него появляется состояние null, которого нет у обычного int.

## 5. Чем отличаются HasValue, Value и оператор ?? ?

- HasValue проверяет, есть ли значение
- Value достаёт само значение
- ?? подставляет значение по умолчанию, если переменная равна null.

## 6. В какой ситуации отсутствие значения является нормальным состоянием данных и поэтому `int?` удобнее обычного int?

- Когда данные необязательны или ещё не введены. В int пришлось бы хранить -1 или 0, что можно перепутать с реальным значением.

## 7. Почему для класса персонажа лучше использовать enum, чем хранить "Warrior", "Mage" и "Archer" в обычной строке?

- Чтобы исключить случайные опечатки, дать компилятору возможность проверять значения при сборке и удобно использовать их в switch.
